1

Chọn folder và tạo nơi lưu tài liệu

Trong Obsidian, nơi lưu toàn bộ ghi chú được gọi là vault.

Vault thực chất là một folder bình thường. Bên trong là các file Markdown .md, hình ảnh và folder cấu hình .obsidian. Obsidian không nhốt dữ liệu của bạn trong một định dạng riêng.

Cách tạo vault mới

Mở Obsidian. Ở màn hình quản lý vault, chọn Create new vault.
Đặt tên dễ nhận ra, ví dụ Starter Vault – Tên của bạn.
Tại Location, bấm Browse và chọn một vị trí rõ ràng trên máy.
Bấm Create. Obsidian sẽ tạo folder vault rồi mở folder đó.
Finder›Documents›Obsidian›Starter Vault – Tên của bạn
Người mới nên chọn một vị trí đơn giản. Gợi ý: Documents/Obsidian/…. Đừng tạo vault bên trong một vault khác. Nếu dùng iCloud, Dropbox hoặc Google Drive, hãy học cách đồng bộ sau khi vault đã chạy ổn định.

OBSIDIAN ⇄ CÙNG MỘT FOLDER TRÊN MÁY ⇄ FINDER

Mở vị trí vault trong Finder

Trong thanh file bên trái của Obsidian, nhấp chuột phải vào một file hoặc folder.
Chọn Show in system explorer / Reveal in Finder (tên có thể khác đôi chút theo phiên bản).
Finder mở đúng vị trí đó. Hãy nhìn tên folder và file để xác nhận.
Bài kiểm tra 30 giây: Tạo một note tên Kiem-tra-vi-tri trong Obsidian. Chuyển sang Finder và tìm file Kiem-tra-vi-tri.md. Thấy file này nghĩa là bạn đã hiểu đúng “hai giao diện, một địa điểm”.
3

Dùng plugin Templates tạo template đầu tiên

Templates là Core plugin có sẵn trong Obsidian; không cần tải từ Community plugins.

A. Tạo folder chứa template

Trong File explorer của Obsidian, tạo folder mới tên Templates.
Mở Settings → Core plugins, tìm Templates và bật công tắc.
Vào Settings → Templates. Ở Template folder location, chọn folder Templates.
Settings › Core plugins › Templates: ON

B. Tạo file template

Tạo note mới bên trong folder Templates, đặt tên Thinking Note, rồi dán nội dung mẫu sau:

---
type: thinking-note
created: {{date}} {{time}}
status: seed
---

# {{title}}

## Điều mình đang nghĩ

## Vì sao điều này quan trọng?

## Bằng chứng / ví dụ

## Bước tiếp theo
- [ ]
Đặt template bên trong vault. Folder Templates phải nằm dưới folder vault. Nếu đặt nó ở ngoài vault, Obsidian Templates sẽ không nhìn thấy.

Đổi màu header bằng CSS snippet

CSS snippet là một file .css nhỏ giúp đổi cách Obsidian hiển thị mà không sửa nội dung note.

A. Mở đúng folder CSS snippets

Mở Settings → Appearance.
Cuộn xuống mục CSS snippets và bấm biểu tượng folder Open snippets folder.
Finder sẽ tự mở đúng folder .obsidian/snippets. Hãy để cửa sổ này mở.
Starter Vault › .obsidian › snippets › heading-colors.css

B. Tạo file CSS bằng TextEdit trên Mac

CSS là file chữ thuần, nhưng đuôi file phải là .css. File heading-colors.txt, heading-colors.css.txt hoặc heading-colors.rtf sẽ không xuất hiện trong Obsidian. Không dùng Word hoặc Pages để tạo file này.
Mở ứng dụng TextEdit và tạo tài liệu mới.
Chọn Format → Make Plain Text, hoặc nhấn ⇧⌘T. Bước này bỏ định dạng chữ đậm, font và màu của TextEdit.
Bấm nút Sao chép bên dưới rồi dán toàn bộ đoạn CSS vào TextEdit.
Chọn File → Save. Đặt tên chính xác là heading-colors.css và tạm lưu ra Desktop cho dễ tìm.
Nếu Mac hỏi dùng đuôi .css hay .txt, chọn Use .css.
Từ Desktop, kéo file heading-colors.css vào cửa sổ folder snippets đang mở.

C. Sao chép đoạn CSS thay màu tiêu đề

/* heading-colors.css — ví dụ màu tiêu đề */
body {
  --h1-color: #e9b40f;
  --h2-color: #1e606e;
  --h3-color: #9a5b00;
}

/* Áp dụng cả khi đọc và khi soạn thảo */
.markdown-rendered h1,
.HyperMD-header-1 { color: var(--h1-color) !important; }

.markdown-rendered h2,
.HyperMD-header-2 { color: var(--h2-color) !important; }

.markdown-rendered h3,
.HyperMD-header-3 { color: var(--h3-color) !important; }
Kiểm tra trước khi quay lại Obsidian: Trong Finder, tên file phải hiện đúng là heading-colors.css. Nếu đang là .txt hoặc .rtf, nhấp chuột phải → Rename, đổi phần cuối thành .css, rồi chọn Use .css khi Mac hỏi xác nhận.

D. Bật snippet trong Obsidian

Quay lại Settings → Appearance → CSS snippets.
Bấm nút Reload snippets (biểu tượng làm mới) nếu chưa thấy file.
Bật công tắc cạnh heading-colors.
Mở một note có # H1, ## H2, ### H3 để quan sát màu mới.
Không thấy folder .obsidian? Đây là folder ẩn. Cách dễ nhất là luôn mở bằng nút Open snippets folder trong Appearance. Trong Finder, có thể nhấn ⌘ + ⇧ + . để hiện/ẩn file ẩn.

Dùng phím tắt để tạo note từ template

Phím tắt giúp biến quy trình nhiều lần bấm thành một thói quen nhanh.

Cách 1 — Dùng Command Palette ngay

⌘+P→ gõ Templates: Insert template → chọn Thinking Note
Nhấn ⌘ N để tạo note mới và đặt tên cho note.
Nhấn ⌘ P để mở Command Palette.
Tìm Templates: Insert template, nhấn Enter, rồi chọn Thinking Note.

Cách 2 — Gán phím tắt riêng

Settings › Hotkeys › tìm Templates: Insert template
Mở Settings → Hotkeys.
Tìm lệnh Templates: Insert template.
Bấm dấu + và gán tổ hợp dễ nhớ. Gợi ý trên macOS: ⌥⌘T.
Tạo note mới, nhấn phím tắt vừa gán, rồi chọn Thinking Note.
⌘+Ntạo note→⌥+⌘+Tchèn template
Phân biệt hai hành động: ⌘ N tạo một note trống; Insert template chèn cấu trúc mẫu vào note đang mở. Muốn “tạo note từ template”, bạn thực hiện hai hành động liên tiếp.
