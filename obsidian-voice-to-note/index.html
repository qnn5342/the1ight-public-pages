01 · Kết quả cuối cùng

Sau bài này, bạn có một workflow ngay trong Obsidian:

Audio Recorder
giữ file gốc
→
Whisper local
audio → text
→
Claudian + AI Agent
text → note

Phần miễn phí: Whisper chạy trên máy, không tính phí theo phút. AI Agent dùng subscription/API của provider bạn chọn.

02 · Hiểu đúng mô hình

Claudian đưa một coding agent vào trong vault. Agent có thể đọc, viết, tìm file và chạy lệnh shell với vault làm working directory.[1] Agent không cần tự “nghe” audio: nó gọi lệnh whisper, đọc transcript rồi sửa note.

Hai lớp độc lập: Whisper lo nhận dạng giọng nói. Codex/Claude Code/OpenCode lo hiểu transcript và tổ chức kiến thức.

LớpViệc làmChi phí
Audio RecorderThu âm và embed file vào noteMiễn phí
Whisper localChuyển audio thành raw transcriptMiễn phí, dùng tài nguyên máy
AI AgentDọn transcript, tóm tắt, tạo action items, sửa noteTheo subscription/API đã chọn

Giới hạn: Claudian hiện là plugin desktop cho Obsidian 1.13.0 trở lên.[1] Bạn có thể ghi âm trên điện thoại và sync vault, nhưng bước agent + Whisper trong guide này chạy trên máy tính.

03 · Chuẩn bị

  • Obsidian Desktop đã mở được vault học tập.
  • Core plugin Audio recorder đã bật.[2]
  • Có Terminal trên macOS/Linux hoặc PowerShell trên Windows.
  • Có subscription/API cho ít nhất một harness được Claudian hỗ trợ.
  • Tạo một note thử nghiệm; chưa chạy trên cả vault quan trọng.

Guide dùng Codex làm đường mặc định vì Claudian hỗ trợ chính thức và Codex có thể đăng nhập bằng ChatGPT Plus, Pro, Business, Edu hoặc Enterprise.[4]

Không dùng Command Code trực tiếp trong bài này. Danh sách harness Claudian hiện công bố gồm Claude Code, Codex, Grok Build, OpenCode, Pi và DeepSeek Harness; Command Code chưa nằm trong danh sách đó.[1]

04 · Cài Codex CLI

macOS hoặc Linux

curl -fsSL https://chatgpt.com/codex/install.sh | sh
codex

Windows PowerShell

powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
codex
  1. Chạy codex.
  2. Chọn Sign in with ChatGPT.
  3. Đăng nhập tài khoản được phép dùng Codex.
  4. Thoát và mở lại Terminal, rồi chạy codex --version.

Nếu lớp đã dùng Claude Code hoặc OpenCode, có thể chọn harness đó trong Claudian. Các bước Whisper phía sau không thay đổi.

05 · Cài plugin Claudian

  1. Trong Obsidian, vào Settings → Community plugins.
  2. Bấm Browse, tìm Claudian, chọn Install rồi Enable.
  3. Mở Settings → Claudian → Providers.
  4. Chọn Codex. Để trống CLI path trước để Claudian tự tìm.
  5. Mở Claudian từ ribbon hoặc Command palette, tạo một chat mới và hỏi: “Hãy cho biết tên vault hiện tại, không sửa file.”

Nếu báo CLI not found, kiểm tra codex --version trong Terminal, restart Obsidian rồi vào provider settings để đặt đúng CLI path. Claudian lưu ý rằng Obsidian mở từ Dock có thể không nhận cùng PATH với Terminal.[1]

06 · Cài Whisper local

Whisper chính thức cần package openai-whisper và chương trình ffmpeg để đọc audio.[3] Model small là lựa chọn mặc định của bài này: đủ tốt cho tiếng Việt nhưng chưa quá nặng.

macOS — đường ngắn nhất

brew install ffmpeg openai-whisper
whisper --help

Nếu chưa có Homebrew, cài từ brew.sh, sau đó chạy lại hai lệnh trên.

Windows — Python + ffmpeg

Cài Python 3.11 trước. Sau đó mở PowerShell:

py -3.11 -m pip install -U openai-whisper
choco install ffmpeg
whisper --help

Nếu không dùng Chocolatey, Whisper cũng hướng dẫn cài ffmpeg bằng Scoop: scoop install ffmpeg.[3]

Kiểm tra với một recording thật

Trong Terminal, kéo file audio từ File Explorer/Finder vào sau dấu ngoặc kép để lấy đúng đường dẫn:

whisper "/duong-dan/Recording.webm" \
  --model small \
  --language vi \
  --task transcribe \
  --output_format txt

Kết quả đúng: lần đầu model được tải xuống; sau đó xuất hiện file Recording.txt có nội dung tiếng Việt. Audio vẫn giữ nguyên.

Không dùng --task translate nếu muốn transcript tiếng Việt. Trong Whisper, “translate” là dịch speech sang tiếng Anh; bài này dùng --task transcribe.[3]

07 · Ghi âm trong Obsidian

  1. Vào Settings → Core plugins, bật Audio recorder.
  2. Mở note cần capture.
  3. Chạy Command palette → Audio recorder: Start recording audio.
  4. Nói một ý hoàn chỉnh: bối cảnh, ý chính và bước tiếp theo.
  5. Dừng recording. Kiểm tra note có audio embed và bấm Play nghe được.

Audio Recorder là core plugin chính thức của Obsidian.[2] Không đổi tên hoặc di chuyển file trước khi agent xử lý.

08 · Bảo Claudian biến recording thành note

Mở Claudian, dùng @ để mention note đang chứa recording rồi gửi prompt sau:

Trong note được @mention có một file audio được embed.

Hãy làm theo đúng thứ tự:
1. Đọc note và xác định chính xác file audio được embed.
2. Giữ nguyên audio gốc; không đổi tên, không di chuyển, không xóa.
3. Dùng Whisper LOCAL bằng lệnh shell, model small, language vi, task transcribe.
4. Nếu file không nằm cùng thư mục với note, hãy tìm đúng attachment trong vault; không đoán đường dẫn.
5. Đọc transcript được tạo ra. Không tự bịa lại tên riêng hoặc câu không nghe rõ.
6. Append ngay dưới audio embed, không overwrite nội dung cũ, theo mẫu:

## Raw transcript
Toàn bộ transcript, giữ đủ ý.

## Ghi chú đã cấu trúc
- Bối cảnh
- Ý chính
- Quyết định hoặc insight

## Việc cần làm
- [ ] Checklist cụ thể

## Chỗ chưa rõ
Các đoạn không nghe chắc; ghi rõ thay vì đoán.

7. Báo lại file audio đã dùng, model Whisper và note đã sửa.

Trong lần đầu: đọc các lệnh agent định chạy trước khi bấm Approve. Cho phép lệnh whisper trên đúng file audio; không cấp quyền xoá hoặc sửa hàng loạt.

09 · Checklist kiểm tra

  • Audio gốc vẫn còn và vẫn Play được.
  • Whisper chạy local; không nhập OpenAI/OpenRouter API key cho bước transcription.
  • Raw transcript xuất hiện đầy đủ trong note.
  • Structured note nằm dưới audio embed, không ghi đè nội dung cũ.
  • Tên riêng, con số và thuật ngữ được kiểm tra lại bằng audio.
  • Action items là việc thật có thể làm, không phải câu tóm tắt chung chung.
  • Agent báo đúng đường dẫn audio và note đã sửa.

Bài test đạt

Ghi một audio 20–30 giây gồm một con số, một tên riêng và một việc cần làm. Workflow đạt khi transcript giữ đúng ba yếu tố đó và note tạo đúng một checkbox hành động.
