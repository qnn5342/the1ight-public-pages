Why 201 exists

Prototype chạy được là điểm bắt đầu. Đoạn khó nằm ở sau đó.

101 mở cửa cho học viên thấy mình có thể build bằng AI. Nhưng sau bản demo đầu tiên, câu hỏi thật xuất hiện: code sửa tiếp thế nào, data nằm đâu, deploy ra sao, GitHub dùng làm gì, automation nối vào đâu.

Gap 01

Mù stack

App chạy được nhưng người build không hiểu frontend, backend, database, deploy và server đang liên quan với nhau thế nào.

Gap 02

Mất kiểm soát

AI sửa code được, nhưng nếu không biết đọc diff, chia task, debug và rollback, sản phẩm càng lớn càng dễ vỡ.

Gap 03

Không có workflow

Build xong một lần chưa đủ. Product/workspace thật cần GitHub, backend decision, deploy hygiene và automation cho việc lặp.

Who this is for

Khóa này không dành cho số đông. Nó dành cho người đã chạm vào vấn đề thật.

201 phù hợp nhất với học viên cũ và non-tech builder đang muốn hiểu công nghệ đủ sâu để build, làm việc với AI/dev, và tự vận hành hệ thống nhỏ.

Core syllabus

9 buổi để hiểu stack làm sản phẩm trong thời AI.

Mỗi buổi có một mental model, một demo thực tế và một artifact/BTVN. Mục tiêu không phải học thật nhiều tool, mà là biết chọn đúng mảnh ghép và dùng AI có kiểm soát hơn.

Buổi 01

Mindset: MVP → Product có thể scale

Gap giữa prototype và product/workspace system; tech literacy map cho non-tech; cách học tech với AI.

Buổi 02

PRD kỹ thuật & 4 flow

PRD v2, main use case, out-of-scope, user flow, business flow, system flow, data flow.

Buổi 03

IDE + CLI Product Cockpit

Làm việc với agent trong IDE: context, task breakdown, diff review, debug, terminal và CLI.

Buổi 04

Skills for Product Building

Dùng skill như playbook để brainstorm, scope MVP, review PRD, QA app và test flow sản phẩm.

Buổi 05

MCP for Product Building

MCP cho browser test, design/prototype, database/schema/docs, repo/GitHub và workspace context.

Buổi 06

GitHub & Version Control

Issue → change → review → commit → deploy; AI review code/change; repo hygiene và rollback mindset.

Buổi 07

Backend Decision Layer

Khi nào dùng Google Sheets, Firebase, Supabase, backend/API custom; schema, CRUD, auth, permission.

Buổi 08

Deploy & Infra Landscape

Vercel, Cloudflare, VPS, Docker, SSH, env vars, secrets, domain, logs và cách chọn đường deploy.

Buổi 09

Automation with n8n

n8n như automation layer: form/input → data store → notification/digest; local/cloud/self-host overview.

What students build
